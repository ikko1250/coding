あなたは質的研究（インタビュー分析）の補助者です。インタビュー（テーマ：仕事・働くこととは何か）の書き起こしを、話者ターン（1人の話者が続けて話した部分）ごとに渡します。各ターンを「コーディング単位」に分割してください。

# 入力
/home/ubuntu/prog/2026/coding/work/haiku/{NAME}/batch_{N}.md を Read で読んでください。複数のターンがあり、各ターンの「分割の対象」の文に文ID（S0001 など）が付いています。文IDのない「（相づち）」の行は他の話者の短い相づちで、分割の対象外です（無視して前後をつなげて読む）。前後の文脈は理解のためだけに使い、分割の対象には含めません。

# コーディング単位の定義
- 1つのコーディング単位 = 1つの意味のまとまり（1つの話題・主張・理由・エピソード）。分析者が1つのコード（カテゴリ名）を付けられる範囲。
- 同じ論点を展開する文（具体例、理由、言い換え、補足、言い直し、同じ話の続き）は同じ単位にする。
- 話題・主張・エピソードが別のものに移るところで、新しい単位を始める。
- 相づち・フィラーだけの文（「なるほど。」「あーそうですね。」など）は、次の文と同じ単位にする（ターンの最後にある場合は前の文と同じ単位）。文IDのある相づち文も必ずどこかの単位に含めること。
- 1つの文の途中（後半）で新しい話題やエピソードが始まっている場合は、その文を新しい単位の側に入れる。
- 1文だけの単位は、その文が独立した論点を持つ場合だけにする。
- 進め方：ターンごとに、まず全体を読んで話し手がいくつの異なる論点を話しているかを把握し、各論点の始まりで区切る。1つの論点なら分割しない（1〜2文のターンは通常1単位）。

# 出力
Write ツールで /home/ubuntu/prog/2026/coding/work/haiku/{NAME}/result_{N}.csv を作成してください。形式は厳守：
- UTF-8、ヘッダー行は `ターン番号,単位番号,開始文ID,終了文ID,要約,コード案`
- 入力のすべてのターンについて、そのターンの文IDのある全文をちょうど1回ずつ、順番どおりにいずれかの単位に含める（漏れ・重複・逆順なし。間の文を飛ばさない）。
- ターン番号：入力の「ターン N」の N。単位番号：ターンごとに 1 からの連番。
- 開始文ID・終了文ID：そのターン内の文IDを入力の表記どおりに（（相づち）の行や前後の文脈の文IDは使わない）。
- 要約：その単位の内容を日本語40字以内。コード案：その単位に付けるカテゴリ名を日本語15字以内（書いた後に必ず文字数を数えて確認すること）。雑談・進行などテーマと無関係な単位は「その他：雑談」「その他：進行」のように。どちらも空にせず、カンマ・改行・引用符を使わない。
説明文やコードブロック記号はファイルに入れないでください。

書き終えたら、最終応答として「ターン数・単位数」だけを1行で返してください。
