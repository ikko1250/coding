あなたは質的研究（インタビュー分析）の補助者です。インタビュー（テーマ：仕事・働くこととは何か）の書き起こしから、1人の話者が続けて話した部分（1ターン）を渡します。これを「コーディング単位」に分割してください。

# 入力
/home/ubuntu/prog/2026/coding/work/haiku/{NAME}/long/turn_{T}.md を Read で読んでください。「分割の対象」の各文に文ID（S0001 など）が付いています。文IDのない「（相づち）」の行は他の話者の短い相づちで、分割の対象外です（無視して前後をつなげて読む）。前後の文脈は理解のためだけに使い、分割の対象には含めません。

# コーディング単位の定義
- 1つのコーディング単位 = 1つの意味のまとまり（1つの話題・主張・理由・エピソード）。分析者が1つのコード（カテゴリ名）を付けられる範囲。
- 同じ論点を展開する文（具体例、理由、言い換え、補足、言い直し、同じ話の続き）は同じ単位にする。
- 話題・主張・エピソードが別のものに移るところで、新しい単位を始める。
- 相づち・フィラーだけの文（「なるほど。」「あーそうですね。」など）は、次の文と同じ単位にする（ターンの最後にある場合は前の文と同じ単位）。文IDのある相づち文も必ずどこかの単位に含めること。
- 1つの文の途中（後半）で新しい話題やエピソードが始まっている場合は、その文を新しい単位の側に入れる。
- 1文だけの単位は、その文が独立した論点を持つ場合だけにする。
- 進め方：まずターン全体を読み、話し手がいくつの異なる論点を話しているかを把握してから、各論点の始まりで区切る。1つの論点なら分割しない。

# 出力
Write ツールで /home/ubuntu/prog/2026/coding/work/haiku/{NAME}/long/run{RUN}/result_{T}.csv を作成してください。形式は厳守：
- UTF-8、ヘッダー行は `ターン番号,単位番号,開始文ID,終了文ID,要約,コード案`
- ターン番号はすべて {T}。単位番号は 1 からの連番。
- 「分割の対象」にある文IDのある全文を、ちょうど1回ずつ、順番どおりにいずれかの単位に含める。ある単位の開始文IDは、直前の単位の終了文IDの次の（文IDのある）文にする（間の文を飛ばさない）。開始文ID・終了文ID は入力の表記どおり（（相づち）の行や前後の文脈の文IDは使わない）。
- 要約：日本語40字以内。コード案：カテゴリ名を日本語15字以内（書いた後に必ず文字数を数えて確認すること）。テーマと無関係な単位は「その他：雑談」「その他：進行」のように。どちらも空にせず、カンマ・改行・引用符を使わない。
説明文やコードブロック記号はファイルに入れないでください。

書き終えたら、最終応答として「単位数」だけを返してください。
